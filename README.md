# Sum up 20 November's world news in one image

Entry for make.fun bounty `news-image-20261120` ($250, deadline 2026-11-22T00:00:00Z).

The program `main.py` (Python 3.13, standard library only, no network) copies
the bundled `entry.png` (1024x1024, under 1 MiB) to `/output/entry.png`.
Running it twice writes the same bytes.

The image is a six-panel newspaper front page for Friday, November 20, 2026:
1. Shenzhen Summit — Trump, Xi and Putin meet, joint peace declaration
2. World Court — ICJ rules Myanmar committed genocide against the Rohingya
3. Russia attacks Kyiv — missile and drone strikes, embassies damaged
4. Houthi missile hits Riyadh skyscraper
5. Markets fall — Nikkei down 4.8%, S&P down 2%
6. COP31 — climate talks in overtime, fossil fuels removed from draft
